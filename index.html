2. The big idea: draw the seam

A wall socket is a seam. The lamp does not care who made the power station, and the power station does not care which lamp you plug in. The Workbench’s rules (is a case overdue?) should be like the lamp: they should not know which AI vendor answers. Class 10 finds where that is not yet true, fixes it, and then lets a second vendor plug in.

5. Ports, adapters and what SOLID means here

A port is a small description of what the core needs, such as “something that can answer one request”. An adapter is one vendor’s way of meeting it. The core is written against the port, so a new vendor means a new adapter and no edit to the core. The five SOLID ideas are not rules to memorise. In this class each one is one thing you can run.

A port, written as a Protocol: no inheritance needed
from typing import Protocol, runtime_checkable

@runtime_checkable
class LlmClient(Protocol):
    def complete(self, request: LlmRequest) -> LlmReply: ...

# Any class with a matching complete() fits. It never has to inherit.
# isinstance(PlainFake(), LlmClient)           -> True
# LlmClient among PlainFake's parents          -> False

Two ways to write a contract, and when each fits:

ToolGood forWhat we saw
typing.ProtocolA shape the core needs. Anyone with the right methods fits, with no import of your base classLlmClient, RecordSource, ReportSink, RunJournal and BatchStore are all Protocols
abc.ABCShared steps that every adapter must follow, with a few holes it has to fillProviderAdapter: an adapter missing _to_reply and _translate cannot even be built, and says so at once

The five ideas, each with the thing you will run in class:

IdeaIn plain wordsWhat we run
S single responsibilityA module has one reason to changeThe judge moves out of the loaders into judge.py
O open for extensionAdd a behaviour without editing the coreA new AlwaysAbstain client works with 0 core files edited
L substitutableA stand-in must behave like the real thingA faithful fake: 3 attempts. A loud fake that raises ValueError: 1 attempt
I small interfacesAsk for the little you useSeparate source and output ports, so a fake needs only what the test touches
D depend on the portThe core imports the port, never the vendorAn architecture test scans the imports and fails if the core imports an adapter
A check that says yes to the wrong thing With @runtime_checkable, isinstance checks the names of the methods and nothing else. A class whose complete takes a plain string passed it: isinstance says: True. It was mypy that caught the wrong shape: Argument 1 to "use" has incompatible type "WrongShape"; expected "LlmClient". The runtime check is a guard against a missing method, and mypy is the check for the signature. Use both.
